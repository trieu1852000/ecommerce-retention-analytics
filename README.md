# E-Commerce Sales & Customer Retention Analytics

## Overview
An end-to-end data analytics project evaluating seasonal revenue trends, product category performance, and customer cohort retention using multi-table transactional e-commerce data (100k+ orders).

* **Tech Stack:** SQL (SQLite, CTEs, Window Functions), Python (Pandas), Tableau Public

## Project Architecture & Methodology
1. **Data Cleaning & Standardization (Python / Pandas):** Parsed timestamps, handled missing values, and standardized English product categories.
2. **Relational Data Modeling & SQL Analytics:** Authored complex SQL queries utilizing CTEs, Multi-Table Joins, and Window Functions to compute Cohort Retention Index, Customer Lifetime Value (CLV), and Average Order Value (AOV).
3. **Business Intelligence & Visualization (Tableau):** Designed an interactive executive dashboard featuring KPI summary cards, seasonal revenue trend lines, top product segment rankings, and a cohort retention heatmap.
